# 📊 EdTech Courses Analysis - Power BI Project

This repository contains my mini project on **Comprehensive Analysis of EdTech Courses in India**, developed using **Power BI**.  
The project leverages interactive dashboards to transform raw data into meaningful insights about the EdTech ecosystem.

## 🔎 Project Overview
- Built an **interactive Power BI report** with multiple KPIs and visualizations.
- Focused on course ratings, views, categories, languages, subtitles, and instructor performance.
- Designed to support **data-driven decision-making** and highlight learner preferences.

## 📂 Report Tabs
1. **Comprehensive Analysis**
   - Course overview (total courses, ratings, views)
   - Top-N & Bottom-N course analysis
   - Category & sub-category distribution
   - Language preference insights

2. **Cohort Analysis**
   - Subtitle impact on course views
   - Duration vs. views relationship

## 🛠️ Tools & Technologies
- Power BI  
- Power Query  
- DAX  
- Data Visualization
